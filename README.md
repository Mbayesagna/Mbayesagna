## Featured project

### [Scolly](https://scolly.org): AI-powered school management SaaS

Founder and solo developer. In production, with monthly and annual plans paid in the app.

- 180+ features, 6 user roles, 27+ generated PDF document types
- Offline-first architecture (IndexedDB, delta sync)
- 5 orchestrated AI flows (DeepSeek-V3, Gemini) for risk analysis, report comments and remediation plans
- Constraint-solver timetable engine
- Online payments (DexPay, Wave, Orange Money)
- 2,500+ tests (Vitest, Playwright), PostgreSQL with row-level security
