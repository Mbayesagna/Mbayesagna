🏫 180+ fonctionnalités, 6 rôles (Directeur, Enseignant, Comptable, Surveillance, Parent, Super Admin), 20 onglets directeur
📡 Architecture 100% Offline-First (IndexedDB + file de synchronisation delta, écritures optimistes)

🗓️ Moteur de génération d'emploi du temps — solveur de contraintes maison (quotas, disponibilités enseignants, salles typées, EPS mutualisé, 5 tentatives seedées), 90+ tests dédiés
🤖 5 flows IA (DeepSeek-V3 + Gemini TTS) : analyse de risque, appréciations automatiques, plans de remédiation, aide à la délibération, proclamation audio
💳 Paiements en ligne via DexPay, portail parent multi-élèves par QR code
✅ 1000+ tests (Vitest + Playwright), 28 tables PostgreSQL avec Row Level Security
