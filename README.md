## Projet Phare — **Scolly**

**SaaS de gestion scolaire intelligent** pour le système éducatif sénégalais (Préscolaire → Lycée)

Développé et commercialisé en solo, de l'architecture à la relation client.

### Points forts

| Fonctionnalité | Détails |
|---|---|
| **180+ fonctionnalités** | 6 rôles (Directeur, Enseignant, Comptable, Surveillance, Parent, Super Admin) |
| **20 onglets directeur** | Dashboard personnalisé par rôle |
| **100% Offline-First** | IndexedDB + file de synchronisation delta, écritures optimistes |
| **27+ types de PDF** | Bulletins, cartes d'identité élève/parent (QR code), factures, reçus |
| **Moteur emploi du temps** | Solveur de contraintes maison (quotas, disponibilités, salles typées, EPS mutualisé) — 90+ tests |
| **5 flows IA** | Analyse de risque, appréciations auto, plans de remédiation, aide délibération, proclamation audio |
| **Paiements en ligne** | DexPay + portail parent multi-élèves (QR code) |
| **1000+ tests** | Vitest + Playwright — 28 tables PostgreSQL avec RLS |

### Stack Scolly

```
Frontend: Next.js 16, React 19, TypeScript, Tailwind CSS
Backend: Node.js, Supabase, PostgreSQL (RLS)
IA: DeepSeek-V3, Gemini TTS
```
